# Запуск финансового кабинета в Telegram

Все команды ниже вводятся в **терминал PowerShell**, открытый в папке `F:\web\expedition`. Файл Activate.ps1 открывать двойным щелчком не нужно: активация окружения не обязательна.

## 1. Окружение

На чистом компьютере установите Python 3.12, откройте терминал в папке проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Последнюю команду выполняйте **только если `.env` ещё нет**. Существующий файл содержит ваши настройки; его перезаписывать нельзя.

## 2. Локальные настройки

Откройте `.env` в редакторе. Не отправляйте его содержимое в чат, не добавляйте в Git или запись экрана.

- `BOT_TOKEN` — существующий токен вашего Telegram-бота.
- `MANAGER_IDS` — числовой Telegram ID менеджера; свой ID можно узнать командой `/id` боту. Несколько ID разделяются запятыми.
- `DATABASE_PATH=data/shop.db` — общая существующая база; не меняйте путь для кабинета.
- `YOOKASSA_PROVIDER_TOKEN` — существующий токен BotFather → Payments → ЮKassa Test. Это **не секретный ключ API магазина**.
- `YOOKASSA_SHOP_ID` — shopId именно того тестового магазина, который подключён в BotFather.
- `YOOKASSA_SECRET_KEY` — секретный API-ключ этого магазина, начинающийся с `test_`. Найдите/создайте его в кабинете ЮKassa, раздел интеграции и ключей API. Он нужен серверу для проверки платежа и выполнения возврата.
- `DEMO_PAYMENTS_ENABLED=true` — отдельный явно обозначенный имитатор для защиты задания без ключей провайдера. Его можно отключить значением `false`.
- `WEB_HOST=127.0.0.1`, `WEB_PORT=8080`, `INIT_DATA_TTL=3600` — оставьте по умолчанию.

Пока API-ключей нет, обычная тестовая оплата через Telegram продолжает работать; настоящий тестовый возврат ЮKassa недоступен. Для полного сценария без провайдера выбирайте в боте «Демонстрация без платёжного провайдера».

## 3. Временный HTTPS-туннель

Установите Cloudflare Tunnel по [официальной инструкции](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/downloads/). На Windows с winget:

```powershell
winget install --id Cloudflare.cloudflared --exact
```

Откройте новый терминал после установки. В отдельном окне запустите:

```powershell
cloudflared tunnel --url http://127.0.0.1:8080
```

Программа напечатает временный адрес `https://…trycloudflare.com`. Запишите **ваш** адрес в `.env`:

```dotenv
MINI_APP_URL=https://ваш-адрес.trycloudflare.com
```

Пример выше — шаблон, а не действующий адрес. Туннель оставьте работающим. Учётная запись Cloudflare для Quick Tunnel не требуется; адрес меняется при новом запуске. Если у вас уже есть конфигурация cloudflared, учитывайте ограничения [Quick Tunnels](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/).

## 4. Бот и сервер

Остановите прежний экземпляр бота через Ctrl+C. В другом терминале:

```powershell
cd F:\web\expedition
.\.venv\Scripts\python.exe run.py
```

Этот процесс запускает и бота, и HTTP-сервер. Второй экземпляр polling того же бота не нужен. После изменения `.env` перезапускайте `run.py`; туннель можно оставить работающим.

В **личном чате** менеджера отправьте `/start`, затем `/cabinet` и нажмите «Финансовый кабинет». Если HTTPS не задан, бот покажет подсказку настройки. `/summary` показывает текущий месяц; `/summary 2026-10-01 2026-10-31` — выбранные даты включительно, по Москве.

Открытие адреса в обычном браузере не даёт доступ к финансовым данным. Mini App получает подписанный Telegram `initData`, сервер проверяет подпись, срок и роль. По истечении часа закройте и откройте кабинет снова. Для кнопки `web_app` используется HTTPS-адрес прямо в сообщении, настройка Menu Button через BotFather не обязательна.

## 5. Если не работает

- «Нет связи»: проверьте оба терминала, адрес и порт; дождитесь запуска сервера. Туннель не заменяет работающий `run.py`.
- «Нет доступа»: `/id` должен входить в `MANAGER_IDS`, кабинет открывается из того же бота; после изменения настроек нужен перезапуск.
- Возврат ЮKassa не подтверждён: проверьте ключи **того же тестового магазина**. Нажмите «Проверить у ЮKassa» после восстановления сети. Pending не уменьшает сводку.
- Port already in use / Telegram conflict: остановите старый процесс бота через Ctrl+C.
- Настоящий платёжный ключ или рабочий provider_token: приложение отклонит их, проект рассчитан на тестовый режим.

Локальный стенд `scripts/preview_finance.py` использует временную базу и синтетическую авторизацию, слушает **8081**. Он предназначен исключительно для локальной проверки UI. **Не направляйте туннель на 8081**. Для демонстрации преподавателю нужен основной `run.py`, порт 8080 и вход через Telegram.
