# Использование AI-помощника

Основное задание: «Продолжите проект бота-магазина Expedition на Python, aiogram и SQLite. Добавьте учебную оплату, общий финансовый журнал, защищённый Telegram Mini App менеджера, расходы, полные возвраты и сводку. Реализуйте требования нового задания преподавателя в существующем проекте».

Уточнения пользователя в этой работе:

1. Тестовые shopId и секретный ключ ещё не записаны в `.env`; пользователь добавит их по инструкции. Значения в переписку не передаются.
2. Готового HTTPS-адреса нет, нужен запуск через временный туннель.

Исправления при разработке:

- Повторные события платежа и возврата защищены уникальными индексами и транзакциями; отдельный тест вызывает ошибку записи журнала и проверяет откат платежа.
- Себестоимость старых заказов не восстановлена из текущего каталога: при отсутствии снимка результат обозначен как неопределённый.
- Нативное подтверждение браузера заменено диалогом внутри Mini App; запрос возврата требует явного действия менеджера.

Помощник реализовал код, выполнил автоматические проверки и проверку UI на временной SQLite. Это не подтверждение живой работы Telegram или ЮKassa с вашими ключами.

## Заполнить студенту после самостоятельной проверки

- Какие команды запуска выполнили сами: …
- Как проверили два аккаунта и роль менеджера: …
- Номер нового учебного заказа и период сводки: …
- Ручной расчёт и совпадение с интерфейсом: …
- Что изменили самостоятельно и почему: …
- Ссылка на собственную запись демонстрации: …

Не заявляйте о проверках, которые ещё не выполняли. Токены, API-ключи и initData в этот документ не включаются.
