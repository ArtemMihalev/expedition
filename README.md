# Expedition — Telegram-бот магазина для путешествий

Учебный проект: бот-магазин товаров для путешествий с каталогом, корзиной, оформлением заказа и панелью менеджера.

**Технологии:** Python 3.11+, aiogram 3, SQLite, python-dotenv

---

## Бизнес-описание

### Кто покупатель и что он хочет получить?

Покупатель — человек, который готовится к поездке или путешествию. Он хочет быстро выбрать и заказать дорожные товары (рюкзаки, органайзеры, адаптеры, аксессуары, тревел-наборы), не заходя на сайт и не звоня в магазин. Бот должен показать каталог, помочь собрать корзину и оформить заказ с самовывозом.

### Что выбирает покупатель и какие сведения нужны для заказа?

1. Товары из каталога (категория → карточка → количество).
2. Имя или псевдоним для выдачи заказа.
3. Способ получения: самовывоз из магазина или пункт выдачи.
4. Способ расчёта: оплата при получении (наличными или картой на месте).

Телефон и адрес не требуются — достаточно имени и выбранного пункта выдачи.

### Что происходит после подтверждения заказа: кто его видит и как меняется статус?

После нажатия «Подтвердить заказ» бот сохраняет заказ в базе SQLite, присваивает уникальный номер и статус **«Новый»**. Покупатель видит номер заказа и может открыть его в разделе «Мои заказы». Менеджер (пользователь с ID из `MANAGER_IDS`) видит список новых заказов и может изменить статус:

| Статус | Значение |
|--------|----------|
| `new`       | Новый — только что оформлен |
| `ready`     | Готов к выдаче |
| `completed` | Выдан покупателю |
| `cancelled` | Отменён |

Покупатель видит актуальный статус в «Моих заказах».

### В какой момент заказ считается оформленным?

Заказ считается оформленным в момент нажатия кнопки **«Подтвердить заказ»** на экране проверки, когда бот атомарно переносит корзину в таблицы `orders` и `order_items`, очищает корзину и показывает номер заказа со статусом «Новый». До этого момента покупатель может изменить корзину или отменить оформление.

**Пример:** покупатель выбирает рюкзак TrekPro и адаптер WorldPlug, меняет количество, указывает имя «Алекс» и самовывоз, проверяет итог 6280 ₽ и нажимает «Подтвердить». Бот сохраняет заказ № 3, показывает сумму и статус «Новый». Менеджер видит заказ и позже меняет статус на «Готов к выдаче».

## Схема пути клиента

```
Старт (/start) → Меню
    → Каталог → Категория → Карточка товара → Добавить в корзину
    → Корзина → +/- / удалить → Оформить
        → Имя → Способ получения → Проверка → Подтвердить → Номер заказа
    → Мои заказы → Детали заказа

Менеджер → Новые заказы → Карточка заказа → Сменить статус
```

## Структура базы данных

```
users          — id (Telegram), platform, username, first_name
products       — id, name, description, price, category, is_available
cart_items     — user_id, product_id, quantity (UNIQUE на пару)
orders         — id, user_id, customer_name, pickup_method, payment_method, total, status, created_at
order_items    — order_id, product_name, product_price, quantity (снимок на момент покупки)
checkout_tokens — token, user_id, order_id (защита от дубликатов при повторном нажатии)
```

Сумма заказа считается на сервере по ценам из БД, а не из текста сообщений.

## Запуск на Windows (чистый компьютер)

### 1. Получить токен бота

1. Откройте Telegram → [@BotFather](https://t.me/BotFather)
2. Отправьте `/newbot`, задайте имя и username (должен заканчиваться на `bot`)
3. Скопируйте выданный токен

### 2. Установка

```powershell
cd F:\web\expedition
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### 3. Настройка `.env`

```powershell
copy .env.example .env
```

Откройте `.env` и заполните:

```env
BOT_TOKEN=ваш_токен_от_BotFather
MANAGER_IDS=ваш_telegram_id
DATABASE_PATH=data/shop.db
```

**Как узнать свой Telegram ID:** напишите боту [@userinfobot](https://t.me/userinfobot) — он пришлёт ваш числовой ID. Укажите его в `MANAGER_IDS`, чтобы видеть панель менеджера.

### 4. Инициализация базы (опционально)

База создаётся автоматически при первом запуске. Для ручной инициализации:

```powershell
python scripts/init_db.py
```

### 5. Запуск бота

```powershell
python run.py
```

В Telegram найдите своего бота и отправьте `/start`.

### 6. Остановка

Нажмите `Ctrl+C` в терминале.

## Вход как менеджер

Менеджер определяется по числовому Telegram ID из переменной `MANAGER_IDS` (можно несколько через запятую: `123,456`). После `/start` у менеджера в меню появляется кнопка **«Новые заказы»**.

## Протокол проверки

| # | Действие | Ожидаемый результат | Как проверить |
|---|----------|---------------------|---------------|
| 1 | Пользователь 1: каталог → 2 товара → изменить qty → удалить 1 | Корзина пересчитывается | Кнопки +/- и 🗑 |
| 2 | Подтвердить заказ | Номер заказа, статус «Новый» | Экран после подтверждения |
| 3 | «Мои заказы» | Заказ виден с верной суммой | Сравнить с корзиной |
| 4 | Перезапуск `python run.py` | Заказ на месте | Повторить п.3 |
| 5 | Пользователь 2 | Не видит корзину и заказы пользователя 1 | Второй аккаунт |
| 6 | Менеджер меняет статус | Покупатель видит новый статус | «Мои заказы» у п.1 |
| 7 | Пустая корзина → оформить | Отказ | Alert «Корзина пуста» |
| 8 | Двойное нажатие «Подтвердить» | Один заказ | Повторный клик → «уже оформлен» |

## Ограничения проекта

- Оплата только «при получении» — реальная онлайн-оплата не подключена.
- Бот не пишет «Оплачено» — статус оплаты не отслеживается.
- FSM-состояния хранятся в памяти; при перезапуске незавершённое оформление сбрасывается (корзина сохраняется в БД).
- Один экземпляр бота на один токен — не запускайте два процесса одновременно.
